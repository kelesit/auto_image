接口名称	根据 SPU ID 获取主图向量数据			
接口地址	/api/ImageAi/getSpuImageVector			
请求方法	POST			
请求参数	参数名称	参数类型	参数值示例	参数说明
	spu_id	int || string	2133479,2133483	必填，SPU ID，多个id用英文逗号隔开

响应示例	{
    "code": 0,
    "data": {
        "success": {
            "2133483": {
                "image_vector": [
                    -0.005658938083797693,
                    -0.02511407621204853,
                    -0.0005299120093695819,
                    -0.004143939819186926,
                    0.031792089343070984,
                    0.08592391759157181,
                    -0.04481916502118111,
                    -0.01823124848306179,
                    -0.042225342243909836
                ]
            }
        },
        "error": {
            "2133484": "没有图片向量数据",
            "2133485": "没有图片向量数据",
            "2133486": "没有图片向量数据"
        }
    },
    "msg": "数据获取成功"
}
